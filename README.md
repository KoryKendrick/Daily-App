# Daily Success

A daily check-in app built around the 4 Pillars: check off two habits under
each pillar every day, track your progress over time, and keep your goals and
prayers in one place.

No build step, no server, no account. It's plain HTML/CSS/JavaScript, and all of
your data stays in your own browser (`localStorage`).

## Features

**Daily checkboxes** — the same eight, in the same four pillars:

| Pillar  | Checkboxes                |
|---------|---------------------------|
| Faith   | Read bible, Prayer        |
| Family  | Marriage, Relationship    |
| Fitness | Exercise, Nutrition       |
| Finance | Learn, Plan               |

A pillar turns lime when both of its boxes are checked, and its counter flips to
`✓✓ 2/2`.

**Bonus points** — *Add Gratitude* and *Add Journal*, one bonus point each per
day. Both stay unlit until that day has an entry, then fill in like a checked
pillar box and show how many entries you wrote. The home screen shows the day
you're viewing; every past day is in the archives under the menu, newest first.

**Tracked progress**
- 1 point per checkbox + 1 per bonus type = **10 points max per day**.
- The chart shows the last 7 days (Daily), last 6 weeks (Weekly), or last 6 months
  (Monthly), with a blue goal line at 8 points a day.
- Header badges show your all-time points and your current daily streak.
- Use `‹` / `›` to look at — and back-fill — previous days. Tap the date to jump
  back to today.

**Goals** — type a goal, tag it to a pillar, check it off when it's done, edit or
delete it later. The home screen shows the current week; once a new week starts
(weeks run Sunday to Saturday) earlier goals move out of the way into the
**Goals Log** in the menu, grouped by week, newest first, and kept forever.

**Prayers** — write a prayer with an optional "who/what", mark it answered when
it is, and keep the whole list as a record. Like goals, the home screen shows
this week and everything older lives in the **Prayer Log** in the menu. Archived
prayers stay editable, so one answered months later can still be marked.

**Menu** (the ☰ button) holds the Prayer Log, Goals Log, Gratitude Archive and
Journal Archive, plus your name — blank on a new install until you set it there. Nothing is ever deleted by archiving — what
leaves the home screen is always in a log.

**Search** filters goals, prayers, and today's gratitude/journal entries, and
filters an open log too.

**Export / Import / Reset** at the bottom of the page. Export shows your data as
JSON with a **Copy** button and a **Save file** button; import accepts either a
pasted backup or a file. The copy/paste route matters because some embedded
viewers block file downloads.

## Running it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Putting it on your phone (free options)

You need a URL to open it on your phone. GitHub Pages is free **only on public
repos** — on a private repo it requires a paid plan. Any of these costs nothing:

**1. Make this repo public, then use GitHub Pages.** Settings → General → Change
visibility → Public, then Settings → Pages → deploy from this branch, root
folder. Nothing personal is in the code — your check-ins, goals and prayers never
leave your own device.

**2. Cloudflare Pages or Netlify** (both free, both work with a *private* repo).
Sign up, connect the repo, and deploy with no build command and the root as the
publish directory. Netlify also lets you drag the folder onto its dashboard
without connecting GitHub at all.

**3. `daily-app-single-file.html`** — the whole app in one file. Email or AirDrop
it to yourself and open it, or drop it on any free host. Regenerate it after
changing the source with:

```bash
node build-single-file.js
```

Once it's open at a URL: **iPhone:** Share → *Add to Home Screen*. **Android:**
menu → *Install app*. It installs as **Daily Success**. Renaming the app later
does not rename a copy already on a home screen — remove that icon and add it
again to pick up the new name. It then opens full-screen like a native app and works
offline — a service worker (`sw.js`) caches the files, and the web app manifest
supplies the icon and theme.

Updates arrive on their own: the service worker fetches from the network first
and only falls back to its cache when there's no connection, so opening the app
after a push shows the new version. There is no need to clear anything.

```
build-single-file.js         bundles the three files into one
daily-app-single-file.html   generated by the line above — do not edit directly
```

## Notes on your data

Everything is stored only in the browser on the device you use. Clearing your
browser's site data erases it, and it does not sync between devices — use
**Export data** on one device and **Import** on the other. Nothing is ever sent
anywhere.

## Customising the checkboxes

The pillars and their checkboxes are defined at the top of `app.js` in the
`PILLARS` array. Add, rename, or remove entries there and the UI, scoring, and
chart follow automatically (`DAY_MAX` recalculates from the list; adjust
`DAY_TARGET` if you want a different goal line).
